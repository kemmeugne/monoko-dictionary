# Course trail production parity

The isolated mock remains the visual reference, while production keeps the
Supabase progress records and the real 20-question exercise engine.

| Behavior | Production contract |
| --- | --- |
| Continuous six-level path | All live lessons stay on one trail with sequential locks. |
| Lesson click | Open the mock-style lesson preview before entering lesson content. |
| Lesson mastery | `pratiquer` at 80% unlocks the next lesson; completed lessons replay. |
| Aller plus loin | Only completed lessons with a routed pool expose the 20-question stage. |
| Lesson distinction | An 80% best score adds the gold enriched ring and retained record. |
| Ordinary gift | A completed non-final lesson exposes one claimable XP gift. |
| Cultural gift | The same claim adds the capsule to the Profile collection. |
| Level milestone | The final node opens a 500 XP medal ceremony, not the challenge directly. |
| Grand défi | A claimed medal unlocks the optional 20-question level challenge. |
| Enriched level | First 80% pass awards 300 XP and upgrades the level and medal permanently. |
| Celebrations | Gift, capsule, medal, and first distinction reveals emit confetti. |
| Reward horizon | Shows the nearest available gift, medal, challenge, or next reward. |
| Developer controls | Presets rebuild real XP/rewards; the next-lesson simulator animates completion and re-arms boundary ceremonies. |
| Profile | Claimed medals, challenge upgrades, capsules, ranking, XP, and streak remain visible. |
| Responsive UI | Desktop sheets are centered; mobile sheets rise from the bottom without overflow. |

Fake learner score setters remain excluded. The mock's completion button exists
only for accounts in `app_developers` and updates that developer's protected
production snapshot; ordinary learners always launch and score the real engine.
