# Guide d'enregistrement — Applications HTML Monɔkɔ

Bonjour,

Vous trouverez ci-joint un fichier ZIP contenant 33 applications d'enregistrement pour compléter le contenu audio du cours de Lingala sur Monɔkɔ.

---

## Comment utiliser chaque fichier

1. **Décompressez le ZIP** sur votre ordinateur.
2. **Ouvrez un fichier `.html`** directement dans votre navigateur (Chrome ou Firefox recommandé). Pas besoin d'internet.
3. Pour chaque ligne :
   - La phrase en **français** est déjà affichée.
   - **Si le champ Lingala est vide** : écrivez la traduction en Lingala avant d'enregistrer.
   - **Si le champ Lingala est déjà rempli** : vérifiez et corrigez si nécessaire, puis enregistrez.
4. Cliquez sur **Enregistrer** pour capter votre voix.
5. Écoutez la lecture avec **Écouter** pour vérifier la qualité.
6. Si l'enregistrement est bon, passez à la ligne suivante.
7. Une fois toutes les lignes enregistrées, cliquez sur **Exporter ZIP** en bas de page.
8. Envoyez-moi le ZIP exporté par WhatsApp ou email.

## Conseils d'enregistrement

- Enregistrez dans un endroit **calme** (pas de bruit de fond).
- Parlez clairement, à vitesse naturelle — pas trop lente, pas trop rapide.
- Pour `1.1_sons_et_alphabet` : dites d'abord la **lettre**, une pause, puis le **mot exemple**.
- Si une ligne vous semble incorrecte ou maladroite, vous pouvez corriger le texte avant d'enregistrer.
- Pas besoin de tout faire en une seule session — l'application sauvegarde votre progression automatiquement dans le navigateur.
