# Monoko Lingala AI

## Liste de 200 Types de Phrases à Produire/Testez

### Objectif

Cette liste sert à construire une base de phrases utile pour :

- traduction vocale français → Lingala
- traduction vocale Lingala → français
- conversation naturelle du quotidien
- compréhension des formulations les plus fréquentes à l'oral

Le but n'est pas de faire des phrases compliquées.

Le but est de créer beaucoup de phrases :

- courtes
- naturelles
- fréquentes
- réutilisables
- bien prononcées dans la vraie vie

Il est aussi important de couvrir, quand c'est pertinent :

- le présent
- le passé
- le futur

Toujours avec des phrases courtes, naturelles et orales.

---

## Méthode de Travail

Pour chaque type de phrase :

1. Formuler une phrase naturelle en français.
2. Donner la meilleure version naturelle en Lingala.
3. Si utile, ajouter une variante orale courante.
4. Préférer les phrases qu'une personne dirait vraiment à l'oral.
5. Quand c'est utile, prévoir une version au présent, une au passé et une au futur.

## Comment Utiliser Cette Liste au Mieux

Pour chaque item, il est utile de produire :

- une phrase affirmative
- si possible une question liée
- si possible une forme négative
- si possible une forme avec une autre personne

### Exemple

Type : Dire qu'on est fatigué

Variantes possibles :

- Je suis fatigué
- Tu es fatigué ?
- Je ne suis pas trop fatigué
- Nous sommes fatigués aujourd'hui

Cela permet de construire rapidement une base plus riche.

## Priorité Maximale

Si le temps est limité, commencer par :

- salutations
- besoins immédiats
- maison
- nourriture
- marché
- déplacement
- santé
- questions fréquentes
- conversation courante

Ce sont les zones les plus utiles pour un système de traduction vocale.

---

## Rappel Important

Ce qui a le plus de valeur pour Monoko aujourd'hui :

- phrases courtes
- phrases naturelles
- phrases fréquentes
- formulations orales réelles
- corrections claires

Ce qui a moins de valeur pour l'instant :

- longues explications grammaticales
- phrases rares
- phrases trop littéraires
- formulations artificielles
